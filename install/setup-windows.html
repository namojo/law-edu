터미널이 처음이면 아래 상세 절차로 내려가세요.

1. 이 문서는 무엇인가

교육에서 쓰는 AI 도구(파이, 안티그래비티, Codex CLI, korean-law-mcp)를 설치하기 전에 한 번만 해 두는 공통 준비입니다. PowerShell 여는 법, Node.js 설치, 실습 전용 폴더·계정 분리까지 다룹니다.

법률 업무 예시: 파이(Pi)에게 "이 폴더의 계약서 초안 3건에서 손해배상 조항만 뽑아 표로 정리해 줘"라고 시키려면, 파이를 실행할 토대(Node.js)와 자료를 둘 안전한 폴더가 먼저 있어야 합니다. 그 토대를 만드는 문서입니다.

이 문서를 끝내면 다른 설치가이드의 "설치 전 확인"은 모두 통과한 상태가 됩니다.

2. 설치 전 확인

항목필요한 것확인·대처
운영체제Windows 10(64비트) 또는 113절 ②에서 확인
저장 공간3GB 이상 여유Node.js 약 100MB + Git 약 400MB + 캐시 여유분
관리자 권한설치 프로그램 실행 권한회사 노트북에서 막히면 우회하지 말고 IT에 "Node.js·Git 설치 권한" 요청
인터넷npm 저장소 접속 가능막히면 문제 해결 C
실습 구글 계정업무·개인 계정과 분리된 계정 1개3절 ⑥에서 만듭니다
선행 설치없음이 문서가 모든 가이드의 출발점

보안 원칙 (이 문서 전체에 적용)

  1. 실제 사건 자료를 실습 폴더에 넣지 않습니다. 실습은 가상 정보로만 합니다.
  2. API 키는 받은 화면에서 바로 입력하고, 문서·메신저·메일에 붙여넣지 않습니다. 보관 위치(예: "회사 비밀번호 관리자")만 기록합니다.
  3. 회사 보안 프로그램(백신·DLP·EDR)이 설치를 막으면 끄지 말고 담당자에게 문의합니다.

7. 문제 해결

A. 'node' 용어가 ... 인식되지 않습니다

전체 문구: node : 'node' 용어가 cmdlet, 함수, 스크립트 파일 또는 실행할 수 있는 프로그램 이름으로 인식되지 않습니다.

  • 원인: 설치 프로그램이 명령 위치(PATH)를 등록했지만, 설치 전부터 열려 있던 창은 옛 정보를 들고 있습니다.

  • 해결:

    1. PowerShell 창을 모두 닫고 새로 엽니다 → node -v 재확인.
    2. 안 되면 PC 재부팅 후 재확인.
    3. 그래도 같으면 설치 여부 확인: 설정 → 앱 → 설치된 앱 에서 Node.js 검색. 없으면 ③단계를 다시 합니다.

B. npm.ps1을 로드할 수 없습니다

전체 문구: npm : 이 시스템에서 스크립트를 실행할 수 없으므로 C:\Program Files\nodejs\npm.ps1 파일을 로드할 수 없습니다.

  • 원인: PowerShell 스크립트 실행 정책이 Restricted로 잠겨 있습니다. Windows 기본 설정에서 종종 발생합니다.
  • 해결: 아래로 본인 계정 범위만 완화합니다 (시스템 전체를 바꾸지 않는 안전한 범위).
PowerShell에 붙여넣기
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

확인 질문에 Y → Enter. 예상 결과: 메시지 없이 프롬프트 복귀, 이후 npm -v 동작.

  • 회사 노트북 주의: 이 정책은 그룹 정책에 의해 재정의됩니다 또는 액세스가 거부되었습니다 로 실패하면 회사 보안 정책이 막는 것입니다. 우회하지 말고 IT 담당자에게 "PowerShell CurrentUser 실행 정책 RemoteSigned 허용"을 요청하세요.

C. npm ERR! code ETIMEDOUT / network request ... failed

  • 원인: 사내 프록시·방화벽·백신이 npm 저장소를 막았거나 회선이 일시적으로 끊겼습니다.

  • 해결:

    1. 브라우저에서 아래가 열리는지 확인합니다. 안 열리면 네트워크 차단입니다.
주소창에 붙여넣기
https://registry.npmjs.org
  1. 사내 Wi-Fi 대신 휴대폰 테더링으로 바꿔 재시도합니다 (교육장에서 가장 빠른 방법).
  2. npm 설치 명령은 여러 번 재실행해도 안전합니다. ↑ → Enter 로 재시도하세요.
  3. 계속 막히면 프록시 설정이 필요합니다. IT 담당자에게 문의하고, 백신을 임의로 끄지 마세요.

D. SmartScreen: Windows의 PC 보호 — 인식할 수 없는 앱의 시작을 차단했습니다

  • 원인: 내려받은 설치 파일의 평판 정보가 부족할 때 뜨는 경고입니다. 파일 손상이 아닙니다.
  • 해결: 다운로드 주소가 nodejs.org 또는 git-scm.com 인지 먼저 확인하고, 맞다면 추가 정보 → 실행.
  • 주소가 위 두 곳이 아니면 실행하지 마세요. 검색 결과 상단 광고 링크에서 가짜 설치 파일을 받는 사고가 실제로 발생합니다. 이 문서의 주소를 직접 붙여넣어 들어가세요.

E. AX실습 폴더를 찾지 못한다 / 한글 경로가 깨진다

  • 증상: cd ...\Desktop\AX실습 이 경로를 찾을 수 없습니다 로 실패.
  • 원인: 따옴표를 빼먹었거나, OneDrive 백업이 켜져 있어 바탕 화면 실제 위치가 C:\Users\이름\OneDrive\바탕 화면 으로 옮겨져 있습니다.

  • 해결:

    1. 경로는 항상 큰따옴표로 감쌉니다.
    2. 진짜 바탕 화면 위치를 확인합니다.
PowerShell에 붙여넣기
[Environment]::GetFolderPath("Desktop")
👀

예상 결과: C:\Users\본인이름\OneDrive\바탕 화면 같은 실제 경로. 그 뒤에 \AX실습 을 붙여 cd 하세요.

  1. 가장 쉬운 방법: 파일 탐색기로 AX실습 을 열고 주소 표시줄 경로를 복사(Ctrl+C) → PowerShell에 cd " 를 치고 붙여넣은 뒤 " 로 닫습니다.

8. 제거·되돌리기

1) 전역 설치한 AI 도구 먼저 제거 — 각 도구 가이드의 제거 절차를 먼저 수행합니다. 예: 파이

PowerShell에 붙여넣기
npm uninstall -g @earendil-works/pi-coding-agent

2) Node.js 제거 — 설정 → 앱 → 설치된 앱 → Node.js 검색 → ⋯ → 제거. 남은 캐시까지 지우려면:

PowerShell에 붙여넣기
Remove-Item -Recurse -Force "$env:APPDATA\npm", "$env:APPDATA\npm-cache" -ErrorAction SilentlyContinue
👀

예상 결과: 메시지 없이 완료 (폴더가 없어도 오류가 나지 않습니다).

3) Git 제거 — 설정 → 앱 → 설치된 앱 → Git → 제거

4) 실습 폴더 삭제 — 바탕 화면 AX실습 을 휴지통으로 옮기고 휴지통도 비웁니다.

5) 실행 정책 되돌리기 (문제 해결 B를 실행했던 경우에만)

PowerShell에 붙여넣기
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy Restricted

6) 권한 회수 — 실습 계정으로 로그인해 둔 서비스가 있으면 아래에서 액세스 권한을 삭제합니다.

주소창에 붙여넣기
https://myaccount.google.com/permissions

발급받은 API 키는 발급처에서 반드시 폐기(revoke) 합니다. 키는 지우기 전까지 계속 유효합니다.

다른 설치 방법

본문의 표준 경로(공식 .msi 설치)로 진행하는 것을 권장합니다. 아래는 해당되는 경우에만 보세요.

  • ARM 노트북 (Surface Pro X 등): nodejs.org에서 자동 인식이 안 되면 운영체제 Windows, 형식 Installer (.msi), 아키텍처 arm64 를 직접 고릅니다. 파일명이 node-v24.18.1-arm64.msi 형태면 맞습니다.
  • 이미 Node.js가 깔려 있는 경우: node -v 가 v22.19.0 이상이면 ③단계를 건너뛰어도 됩니다. 그보다 낮으면 nodejs.org에서 최신 LTS .msi 를 그대로 덮어 설치하면 갱신됩니다.
  • 패키지 관리자(winget, Chocolatey): 이 교육에서는 회사 노트북 권한 문제가 잦아 검증·지원하지 않습니다. 사내 표준 배포 절차가 따로 있다면 IT 담당자의 안내를 따르세요.
  • 압축본(.zip) 설치: PATH를 손으로 등록해야 해서 초보자에게 권하지 않습니다.
