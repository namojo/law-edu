1. 이 도구는 무엇인가

안티그래비티는 구글이 만든 에이전트 작업 환경입니다. 한 줄씩 지시하는 대신 "이 폴더의 문서들을 읽고 쟁점을 정리해 줘"처럼 목표를 말하면 AI가 여러 단계를 스스로 나눠서 수행하고, 그 과정과 결과물을 화면에 남깁니다.

법률 업무 예시: AX실습 폴더에 가상 임대차 계약서 3건을 넣고 "세 계약서의 차임 인상 조항을 비교해 표로 정리해 줘"라고 요청하면, 파일을 하나씩 읽고 비교표 문서를 만들어 폴더에 저장합니다.

이 가이드는 무료 데스크톱 앱 Antigravity 2.0 기준입니다. 다운로드 페이지에 네 가지가 있으니 맨 위 하나만 받으세요.

이름무엇인가우리 교육에서
Antigravity 2.0에이전트에게 일을 시키고 결과를 모아 보는 데스크톱 앱← 이걸 설치합니다
Antigravity IDE코드를 직접 쓰는 개발자용 편집기설치 안 함
Antigravity CLI검은 터미널 화면 전용 버전설치 안 함
Antigravity SDK파이썬으로 에이전트를 만드는 개발 키트설치 안 함

⚠️ 보안 안내 (이 문서 전체에 적용)

  • 실제 사건 파일이 있는 폴더를 열지 마세요. AX실습 폴더만 사용합니다.
  • 회사 보안 프로그램(백신·DLP·매체제어)이 막으면 절대 임의로 끄지 말고 전산·보안 담당자에게 문의하세요. 임의 해제는 그 자체가 사고입니다.
  • API 키·비밀번호는 문서·메모·카카오톡·메일에 붙여넣지 마세요. 화면에서 바로 입력하고 "어디에 보관했는지"만 적어 둡니다.
  • 회사 노트북 설치 정책이 있다면 그 정책이 이 가이드보다 우선합니다.

7. 문제 해결

증상 1 — Microsoft Defender SmartScreen에서 인식할 수 없는 앱의 시작을 차단했습니다.

  • 원인: 다운로드 수가 적은 새 설치 파일에 대한 윈도우 기본 경고. 바이러스라는 뜻이 아닙니다.
  • 해결: antigravity.google/download 에서 직접 받았는지 확인한 뒤 추가 정보 → 실행. 출처가 불확실하면 삭제하세요. 회사 백신이 차단한 경우라면 끄지 말고 담당자에게 문의합니다.

증상 2 — Your account is not eligible to use Antigravity

  • 원인: ① 회사 Workspace 계정 로그인(관리자가 AI 기능 차단), ② 만 18세 미만 또는 연령 미확인, ③ 계정 국가 설정이 미지원 지역.
  • 해결: 개인 @gmail.com 계정으로 로그아웃 후 재로그인. 그래도 안 되면 구글 계정에서 연령 확인을 완료하거나 국가 설정을 확인합니다. 회사 계정 차단은 개인이 풀 수 없으니 실습 계정으로 진행하세요.

증상 3 — 브라우저에서는 로그인됐는데 앱은 그대로 로그인 화면

  • 원인: 기본 브라우저가 크롬이 아니거나, 보안 프로그램이 앱 간 연결을 차단.
  • 해결: Windows 키 + R 에 아래를 붙여넣어 기본 브라우저를 Chrome 으로 바꾼 뒤, 앱을 완전히 종료하고 다시 로그인합니다. 브라우저에 "Open Antigravity" 링크가 보이면 그것을 클릭하세요.
검색창에 입력
ms-settings:defaultapps

증상 4 — 앱이 실행되자마자 꺼짐 / 창이 하얗게만 나옴

  • 원인: 설치가 중간에 끊겼거나 이전 설정 파일이 깨진 경우.
  • 해결: ① 재부팅. ② 제거(8절) 후 설치 파일을 다시 받아서 설치. ③ 그래도 같으면 파일 탐색기 주소창에 아래를 붙여넣고 Antigravity 폴더를 다른 곳으로 옮긴 뒤(삭제 대신 이동) 앱을 다시 실행합니다.
검색창에 입력
%APPDATA%

증상 5 — 에이전트가 실습 폴더 밖의 파일을 건드리려고 함

  • 원인: 프로젝트에 상위 폴더(바탕 화면 전체 등)가 추가되어 있습니다.
  • 해결: 즉시 Stop 을 누르고 프로젝트 설정에서 AX실습 외 폴더를 모두 제거합니다. 실제 사건 파일이 열린 정황이 있으면 강사와 소속 정보보호 담당자에게 알리세요.

8. 제거·연동 해제

프로그램만 지우면 구글 계정에 준 권한은 남습니다. 권한 회수(8-3)까지 하세요.

8-1. 프로그램 제거

Windows 키 + R 에 아래를 붙여넣고 Enter.

검색창에 입력
