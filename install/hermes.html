실제 설치 명령·다운로드 주소·계정은 교육 당일 배포 가이드에 있습니다. 이 문서는 그 가이드를 어떻게 안전하게 따라가는지를 안내합니다.

1. 이 도구는 무엇인가

헤르메스는 여러 AI 에이전트에게 일을 나눠 주고 결과를 모아 한 번에 보고하는 "조율 담당" 에이전트입니다. 도구를 하나씩 오가며 지시하는 대신 한 번 요청하면 알맞은 담당 에이전트에게 일을 분배하고, 끝나면 메신저로 알림을 보냅니다.

법률 업무 예시: "이 가상 사건의 쟁점을 정리하고, 관련 법령을 찾고, 상대방 주장 반박 초안을 잡아 줘" 한 번 요청 → 조사·법령검색·초안작성을 각각 담당 에이전트에 맡기고 세 결과를 하나의 보고로 묶어 줍니다. 그 사이 다른 일을 하다가 알림을 받고 확인하면 됩니다.

⚠️ 이름이 같은 다른 도구 주의 — 오설치 사고가 실제로 자주 납니다.
인터넷에 "Hermes Agent" 를 검색하면 Nous Research가 2026년 2월 공개한 오픈소스 AI 에이전트(github.com/NousResearch/hermes-agent, hermes-agent.nousresearch.com)가 나옵니다. 한국어 블로그·강의 자료도 많아 착각하기 쉽습니다.
이것은 우리가 쓰는 헤르메스가 아닙니다. 이름만 같은 별개의 도구입니다.
검색으로 나온 한 줄 설치 명령(curl ... | sh 형태 등)을 실행하면 교육과 무관한 프로그램이 설치되고 터미널 실행 권한까지 갖게 됩니다.
우리 교육의 헤르메스는 길드에서 직접 받은 배포 가이드로만 설치합니다.

🔐 보안 원칙 (전 과정 적용)

  • API 키·비밀번호를 문서·메모·카카오톡·메일에 적지 마세요. 화면에서 바로 입력하고 "어디에 보관했는지"만 기록합니다.
  • 배포 가이드의 키를 채팅방에 붙여넣어 질문하지 마세요. 질문할 땐 키 부분을 가리고 캡처합니다.
  • 회사 보안 프로그램이 막으면 임의로 끄지 말고 담당자에게 문의하세요.
  • 실습은 AX실습 폴더에서만. 실제 사건 자료 폴더와 반드시 분리합니다.

3. 설치 절차

배포 가이드의 순서를 그대로 따르는 것이 원칙입니다. 아래는 그 가이드를 안전하게 따라가는 방법입니다.

1단계 — 배포 가이드와 계정 받기

받은 문서를 끝까지 한 번 훑어보고, 맨 앞의 "요구사항 / 사전 준비" 항목을 먼저 확인합니다.

이 시점에 없으면 진행 불가: 배포 가이드, 길드 계정. 하나라도 없으면 설치를 시작하지 말고 Facilitator에게 바로 요청하세요.

2단계 — PowerShell 열기

시작 버튼을 클릭하고 아래를 붙여넣은 뒤 Enter.

PowerShell에 붙여넣기
powershell
👀

예상 결과: 파란색 또는 검은색 창이 열리고 PS C:\Users\사용자이름> 뒤에 커서가 깜빡입니다. 이 상태가 정상입니다.

관리자 권한이 필요하다고 적혀 있으면: 검색 결과의 Windows PowerShell 을 마우스 오른쪽 클릭 → 관리자 권한으로 실행 → 예. 창 제목에 관리자: 가 붙습니다.

⚠️ 관리자 권한은 배포 가이드가 명시적으로 요구할 때만 사용하세요.

3단계 — 명령 옮겨 적기 (직접 타이핑 금지)

배포 가이드에서 명령 한 줄을 드래그해 Ctrl + C → PowerShell 창을 클릭하고 Ctrl + V.

👀

예상 결과: 명령이 한 줄로, 잘리지 않고 들어갑니다. 눈으로 확인한 뒤 Enter.

한 번에 한 줄씩. 여러 줄을 한꺼번에 붙여넣으면 어디서 실패했는지 알 수 없습니다.

💡 실행 전 30초 습관: 무슨 일을 하는 명령인지 모르겠으면 실행 전에 강사에게 "이 줄은 무엇을 하나요"라고 물어보세요. 특히 Set-ExecutionPolicy, -Force, rm, del 처럼 보안 설정이나 삭제로 보이는 단어가 있으면 반드시 확인 후 실행합니다.

5. 초기 설정·연동

5-1. 로그인

배포 가이드가 안내한 방법(브라우저 로그인 또는 화면 입력)으로 길드 계정에 로그인합니다.

  • 비밀번호·키는 그 자리에서 바로 입력하고 화면 캡처를 남기지 마세요.
  • 로그인 정보를 메모장 파일에 저장하는 것은 금지입니다. 브라우저 비밀번호 관리자나 사내 허용 저장소만 사용하세요.

5-2. 권한 승인 — 무엇을 위임하는지 읽고 승인

헤르메스는 다른 에이전트와 도구에 일을 대신 시키는 도구입니다. 승인하는 권한의 범위가 곧 "헤르메스가 내 대신 할 수 있는 일"의 범위입니다.

허용을 누르기 전에 아래를 확인하세요.

5-3. 메신저 알림 범위 설정 — 사건 정보 미포함

메신저 알림은 회사 밖 서버를 거쳐 개인 휴대폰으로 갑니다. 알림 본문에 사건 정보가 담기면 그 자체가 비밀유지의무 위반 소지가 됩니다.

  • ✅ 좋은 알림: 작업 1 완료 (3건 처리) / 요청하신 검토가 끝났습니다. 결과는 프로그램에서 확인하세요.
  • ❌ 있어서는 안 되는 알림: 의뢰인 이름, 사건번호, 상대방 이름, 계약 금액, 문서 원문 일부.

배포 가이드의 알림 설정 항목에서 두 가지를 지정합니다.

  1. 알림 내용 → "완료 여부만 / 결과 요약 미포함"
  2. 알림 대상 → 본인 1:1 방 (업무 단체방은 절대 지정하지 마세요)

7. 문제 해결

증상 1 — 배포 가이드나 계정을 못 받았다 / 링크가 안 열린다

  • 원인: 안내 메일 누락, 계정 발급 지연, 사내 메일 필터.
  • 해결: 스팸함을 먼저 확인하고, 없으면 Facilitator에게 바로 요청하세요. 혼자 해결할 수 없고, 인터넷에서 찾은 설치 방법으로 대체해서도 안 됩니다(1절 동명 도구 경고). 기다리는 동안 setup-windows.md 를 끝내 두면 시간이 절약됩니다.

증상 2 — '...'은(는) 내부 또는 외부 명령, 실행할 수 있는 프로그램 또는 배치 파일이 아닙니다.

  • 원인: ① 선행 프로그램(예: Node.js) 미설치, ② 설치는 했으나 터미널을 다시 열지 않아 윈도우가 아직 인식하지 못하는 상태.
  • 해결: PowerShell을 완전히 닫고 새로 여세요. 대부분 이것으로 해결됩니다. 그래도 같으면 아래로 Node.js를 확인하고(v22.x.x 형태가 나와야 정상), 안 나오면 setup-windows.md 로 돌아갑니다.
PowerShell에 붙여넣기
node -v

증상 3 — 요청을 보냈는데 응답이 없고 계속 대기

  • 원인: 네트워크 지연, 사내 방화벽 차단, 또는 로그인 세션 만료.
  • 해결: ① 2분 기다립니다(여러 에이전트를 거치므로 일반 챗봇보다 느립니다). ② 그래도 멈춰 있으면 종료·재실행해 로그인 상태부터 확인. ③ 개인 핫스팟에서는 되고 회사 와이파이에서만 안 되면 사내 방화벽 문제입니다 — 임의로 우회하지 말고 담당자에게 문의하세요.

증상 4 — 알림이 오지 않는다 / 반대로 내용이 너무 자세히 온다

  • 원인: 알림 연동 누락, 또는 알림 범위가 기본값.
  • 해결: 5-3으로 돌아가 대상(본인 1:1 방)과 범위를 다시 설정하고 6절 테스트로 실제 문구를 확인합니다. 내용이 자세히 오는 쪽이 더 위험합니다. 고치기 전까지 실제 업무 관련 요청을 넣지 마세요.

증상 5 — 보안 프로그램이 설치·실행을 차단한다

  • 원인: 사내 백신·DLP·매체제어 정책. 내부 배포 도구는 서명 정보가 등록되어 있지 않아 자주 걸립니다.
  • 해결: 백신을 끄거나 예외 등록을 스스로 하지 마세요. 차단 팝업을 캡처해 ① 사내 전산·보안 담당자와 ② Facilitator에게 함께 전달하고 지침을 기다립니다. 급하면 개인 노트북으로 전환하는 편이 안전합니다.

증상 6 — 검색해서 나온 "Hermes Agent"를 이미 설치해 버렸다

  • 원인: Nous Research의 동명 오픈소스 도구를 우리 교육 도구로 착각한 경우.
  • 해결: 실행하지 말고 제거하세요. Windows 키 + R 에 아래를 붙여넣어 설치된 앱을 열고 찾아서 제거합니다. 설치 과정에서 API 키를 입력했다면 해당 키를 발급처에서 즉시 폐기·재발급하고 Facilitator에게 알린 뒤 정식 배포 가이드로 다시 시작하세요.
검색창에 입력
ms-settings:appsfeatures

8. 제거·연동 해제

순서는 연동 해제 → 계정 정리 → 프로그램 제거 입니다. 프로그램만 지우면 위임한 권한이 남습니다.

8-1. 메신저 알림 연동 해제 (가장 먼저)

헤르메스의 알림 설정에서 연동을 해제하고, 메신저 앱 쪽에서도 연결된 앱/봇 목록에서 헤르메스 항목을 삭제합니다. 한쪽만 지우면 알림이 계속 옵니다.

👀

예상 결과: 6절 테스트를 다시 돌려도 알림이 오지 않습니다.

8-2. 계정·권한 회수

  1. 배포 가이드의 계정 관리 항목에 따라 로그아웃하고 저장된 로그인 정보를 지웁니다.
  2. 길드 계정 비활성화·삭제는 Facilitator에게 요청하세요. 개인이 임의로 처리할 수 없습니다.
  3. 발급받은 API 키가 있다면 폐기를 요청하세요. 안 쓰는 키를 남겨 두지 않는 것이 원칙입니다.

8-3. 프로그램 제거

배포 가이드에 제거 절차가 있으면 그 절차를 우선 따릅니다. 없으면 Windows 키 + R 에 아래를 붙여넣고 설치된 앱에서 검색해 ⋯ → 제거.

검색창에 입력
ms-settings:appsfeatures

⚠️ 명령으로 설치한 경우 제거 명령도 배포 가이드에 있습니다. 추측한 명령을 실행하지 마세요.

8-4. 실습 자료 정리

바탕 화면\AX실습 에서 남길 결과물만 옮기고 나머지는 삭제합니다. 실제 사건 정보를 입력한 적이 있다면 해당 파일과 대화 기록을 반드시 삭제하고 강사에게 알리세요.

막히면: 오류 화면을 그대로 캡처(Windows 키 + Shift + S)해 Facilitator 에게 보내세요. 단, 비밀번호·API 키가 보이면 그 부분을 가리고 보내야 합니다. 오류 메시지는 요약하지 말고 글자 그대로 전달하는 것이 가장 빠릅니다.
