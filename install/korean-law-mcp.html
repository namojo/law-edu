1. 이 도구는 무엇인가

korean-law-mcp는 법제처 국가법령정보센터의 공식 데이터(법령·판례·헌재결정·조례·해석례 등 42개 API)를 AI 도구 안에서 바로 불러 쓸 수 있게 연결해 주는 MCP 서버입니다. MCP(Model Context Protocol)는 AI에게 "이런 자료를 조회할 수 있는 창구"를 붙여 주는 표준 규격입니다. 한 번 연결해 두면 안티그래비티나 Codex CLI 안에서 "근로기준법 제74조 알려줘"라고만 해도 법제처 원문을 그대로 가져옵니다.

법률 업무 예시 — AI가 써 준 서면 초안에 민법 제9999조처럼 존재하지 않는 조문이 섞여 있을 때, verify_citations 기능이 인용 조문을 법제처 원문과 하나씩 대조해 "이 조문은 없습니다"라고 잡아 줍니다. 4차시(리서치 검증)의 핵심 도구입니다.

중요 — 이 도구는 조회 결과를 가공·요약할 수 있습니다. 법적 효력이 필요한 판단에는 반드시 국가법령정보센터 원문을 직접 확인하세요. 공식 저장소도 같은 취지를 명시합니다.

보안 규칙 (문서 끝까지 적용)

  • 발급받은 인증키(OC)는 본인만 쓸 수 있습니다. 남에게 알려 주거나 공용 문서·단톡방에 붙여넣지 않습니다.
  • 이 문서나 메모장에 키를 적지 마세요. 발급 화면에서 복사해 설치 화면에 바로 붙여넣고, "법제처 사이트 → API인증키관리에서 언제든 다시 볼 수 있다"는 사실만 기억하면 됩니다.
  • https://mcp.gomdori.app/law?oc=본인키 형태의 주소는 그 자체가 비밀번호와 같습니다 (주소 끝에 키가 들어 있음). 화면 공유·스크린샷 때 가려 주세요.
  • 회사 보안 프로그램이 설치를 막으면 임의로 끄지 말고 전산 담당자나 교육 진행자에게 문의합니다.

5. 초기 설정·연동

5-1. 도구 승인 화면에서 무엇을 위임하는가

처음 쓸 때 "이 도구를 사용해도 될까요?"라는 승인 창이 뜹니다. 이 도구가 하는 일은 법제처 공개 API에 조회 요청을 보내고 결과를 받아오는 것뿐입니다. 내 컴퓨터의 파일을 읽거나 고치지 않습니다. 문구를 읽고 승인하세요.

5-2. 인증키를 환경변수로 두기 (선택 — 터미널에서 직접 쓸 때만)

3-3 마법사를 썼다면 이 단계는 필요 없습니다.

지금 연 PowerShell 창에서만 쓰려면 (본인키를 발급받은 값으로 바꿉니다):

예상 결과 — 성공: 지정한 값을 저장했습니다. 가 표시됩니다. 설정 후 PowerShell 창을 닫았다 다시 열어야 적용됩니다.

setx로 저장하면 인증키가 Windows 사용자 환경변수에 평문으로 남습니다. 공용 PC에서는 쓰지 마세요.

7. 문제 해결

① 플러그인 설치 중 Permission denied (publickey)

증상

복사해서 쓰기
Failed to install: Failed to clone repository: Cloning into
  '/Users/<user>/.claude/plugins/cache/temp_github_<id>'...
  git@github.com: Permission denied (publickey).
  fatal: Could not read from remote repository.

원인 — 설치기가 GitHub에 SSH로 접속하려 했는데 SSH 키가 등록돼 있지 않습니다. Git을 처음 쓰는 분에게 자주 생깁니다.

해결 — 아래 한 줄을 실행한 뒤 설치를 다시 합니다. 앞으로 GitHub 접속을 HTTPS로 바꾸라는 설정이며, 그대로 둬도 문제없습니다.

PowerShell에 붙여넣기
git config --global url."https://github.com/".insteadOf "git@github.com:"

② 사용자 정보 검증에 실패하였습니다 또는 [EXTERNAL_API_ERROR] fetch failed

증상 — 조회할 때마다 위 문구나 fetch failed가 나옴.

원인 — ⓐ 인증키가 틀렸거나, ⓑ 키 앞뒤에 공백·줄바꿈이 섞여 붙여넣어졌거나, ⓒ 법제처 신청이 아직 처리되지 않았습니다.

해결 — ① 법제처 사이트 API인증키관리에서 현재 값을 다시 확인합니다. ② 붙여넣은 뒤 Backspace로 뒤쪽 빈칸이 없는지 확인합니다. ③ 아래로 마법사를 다시 실행해 키를 새로 입력하고 AI 프로그램을 재시작합니다.

PowerShell에 붙여넣기
npx korean-law-mcp setup

③ AI가 법제처 도구를 쓰지 않고 그냥 아는 대로 답함

증상 — 조문을 물었는데 도구 호출 표시 없이 답만 나오고, 그 답이 실제 조문과 다름.

원인 — 설정 후 프로그램을 재시작하지 않았거나, 도구 사용 승인이 꺼져 있습니다.

해결 — ① AI 프로그램을 완전히 종료했다가 다시 실행합니다. ② claude.ai 웹이라면 설정 → 커넥터 → korean-law → 구성에서 도구를 "항상 사용" 으로 바꿉니다. ③ Codex CLI라면 codex mcp list로 목록에 있는지 확인합니다. ④ 그래도 안 되면 프롬프트에 명시합니다.

복사해서 쓰기
korean-law 도구를 써서 법제처 원문으로 확인해 줘.

④ 사내망·보안 프로그램 때문에 조회가 실패함

증상 — 브라우저로는 법제처 사이트가 열리는데, AI 도구에서만 fetch failed가 남.

원인 — 회사 방화벽이나 SSL 검사(SSL inspection) 장비를 거치는 환경에서는 브라우저와 Node.js가 서로 다른 인증서·프록시 설정을 쓰기 때문에 프로그램만 실패할 수 있습니다.

해결 — 보안 프로그램을 끄지 마세요. 전산 담당자에게 사내 프록시 주소를 확인해 아래를 관리자 권한 PowerShell에서 실행하고 재시작합니다 (프록시주소를 받은 값으로 바꿉니다).

PowerShell에 붙여넣기
setx LAW_EXTERNAL_HTTPS_PROXY http://프록시주소:8080 /M

검색하면 LAW_EXTERNAL_TLS_REJECT_UNAUTHORIZED 0으로 인증서 검사를 끄라는 안내가 나오지만, 이는 원인 진단용 임시 조치입니다. 상시 설정으로 쓰지 말고, 교육 중이라면 진행자에게 먼저 알리세요.

⑤ 조문은 잘 나오는데 판례 본문이 비어 있음

증상 — 판례 목록은 뜨는데 본문이 없거나 짧게 잘림.

원인 — 법제처 API가 일부 판례(특히 국세청 출처) 본문을 내려 주지 않아, 도구가 국세청 서버에서 보완 조회를 시도하는데 그 연결이 막힌 경우입니다.

해결 — 다시 한 번 요청해 봅니다(일시적 실패가 잦습니다). 계속 비어 있으면 아래 주소에서 사건번호로 직접 검색합니다. 어차피 법적 판단에는 원문 확인이 필수입니다.

주소창에 붙여넣기
https://www.law.go.kr
