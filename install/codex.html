작성일 기준: 2026-08-01. 명령·주소는 작성일에 OpenAI 공식 저장소(github.com/openai/codex)와 공식 문서(developers.openai.com/codex)에서 확인한 내용입니다. 화면 문구는 버전에 따라 조금 다를 수 있습니다.

소요 시간: 설치 3분 + 로그인 2분 + 첫 테스트 5분. 막히면 7절 문제 해결로.

1. 이 도구는 무엇인가

Codex CLI는 OpenAI가 만든 터미널(글자로 컴퓨터에 명령을 내리는 검은 창)용 AI 작업 도구입니다. 창을 하나 열어 두고 한국어로 지시하면, AI가 내 컴퓨터의 폴더와 파일을 직접 읽고 고쳐 줍니다. 이 과정에서는 같은 일을 다른 AI에게 한 번 더 시켜 결과를 비교하는 용도로 씁니다.

법률 업무 예시 — 자문 메모 20건이 흩어져 있는 폴더에서 이 폴더의 메모들을 쟁점별로 묶어서 목록 표로 정리해 줘라고 지시하면, 파일을 하나씩 읽어 표로 만든 정리본을 만들어 줍니다.

먼저 알아 둘 것

  • Codex CLI는 지시하면 내 컴퓨터의 파일을 실제로 고칩니다. 실습 폴더(바탕 화면\AX실습) 안에서만 쓰고, 실제 사건 자료 폴더에서는 절대 실행하지 않습니다.
  • WSL2는 필요 없습니다. 예전 안내와 달리, 작성일 기준 공식 문서는 PowerShell에서 그대로 실행되는 네이티브 Windows 지원을 기본으로 안내합니다.
  • Codex CLI는 파일을 고치거나 명령을 실행하기 전에 "이렇게 해도 될까요?"라고 묻습니다. 내용을 읽고 승인하고, "전부 자동 승인" 옵션은 교육 중에 켜지 않으며, 실습 폴더 밖 경로는 거절합니다.

보안 규칙 (문서 끝까지 적용)

  • API 키·비밀번호를 이 문서, 메모장, 카카오톡·메일 어디에도 적지 않습니다. 화면에 바로 입력하고 어디에 보관했는지만 적어 둡니다.
  • 실습에는 업무 계정이 아닌 실습용 ChatGPT 계정을 씁니다.
  • 회사 보안 프로그램(백신·EDR)이 설치를 막으면 임의로 끄지 말고 전산 담당자나 교육 진행자에게 문의합니다.

2. 설치 전 확인

PowerShell에 붙여넣기
winver

공식 문서는 Windows 11을 "가장 안정적인 기준", Windows 10 1809 이상을 "동작하지만 안정성이 낮음"으로 안내합니다. 그보다 낮은 버전은 권장하지 않습니다.

3. 설치 절차

3-1. PowerShell 열기

시작 버튼(윈도우 로고)을 누르고 아래를 그대로 입력한 뒤 Enter를 누릅니다.

검색창에 입력
PowerShell
👀

예상 결과 — 파란색(또는 검은색) 창이 열리고 마지막 줄이 PS C:\Users\내이름>로 끝납니다.

복사·붙여넣기 방법: 이 문서의 블록 오른쪽 "복사" 버튼을 누르고, PowerShell 창을 클릭한 뒤 Ctrl+V(또는 마우스 오른쪽 버튼 한 번)를 누릅니다. 붙여넣은 다음 반드시 Enter를 눌러야 실행됩니다.

3-2. 설치 명령 실행

아래 한 줄을 붙여넣고 Enter를 누릅니다.

PowerShell에 붙여넣기
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
👀

예상 결과 — ==>로 시작하는 진행 메시지가 여러 줄 지나가고, 마지막에 설치 완료와 함께 PS C:\Users\내이름> 입력 대기 줄로 돌아옵니다.

⚠️

이렇게 나오면 오류

화면에 나온 문구볼 곳
이 시스템에서 스크립트를 실행할 수 없으므로 ... 파일을 로드할 수 없습니다.7절 ① → 9절 A(winget)로 우회
irm : 원격 서버에 연결할 수 없습니다7절 ④

이 명령이 하는 일: OpenAI 공식 주소(chatgpt.com)에서 설치 스크립트를 내려받아 실행합니다. -ExecutionPolicy ByPass는 "이번 창에서만 스크립트 실행 제한을 풀겠다"는 뜻이고, 창을 닫으면 원래대로 돌아갑니다. 프로그램은 C:\Users\<내이름>\AppData\Local\Programs\OpenAI\Codex\bin에 설치되고 이 폴더가 자동으로 PATH에 등록됩니다. 이런 형태의 명령은 공식 문서에 적힌 주소일 때만 실행하세요 — 검색해서 나온 블로그의 비슷한 명령을 붙여넣지 않습니다.

3-3. PowerShell 창을 닫았다가 다시 열기

창 오른쪽 위 X를 눌러 완전히 닫고, 3-1을 다시 해서 새 창을 엽니다.

👀

예상 결과 — 새 창이 열립니다. (설치로 바뀐 PATH는 새로 연 창부터 적용되므로 이 단계는 건너뛸 수 없습니다.)

이 승인 화면에서 무엇을 위임하는가: "내 ChatGPT 계정의 사용 권한을 이 컴퓨터의 Codex 프로그램이 쓰도록" 허용하는 것입니다. 문구를 읽고 나서 승인하세요. 로그인 정보는 C:\Users\<내이름>\.codex\auth.json 또는 Windows 자격 증명 저장소에 보관됩니다. 공식 문서도 "액세스 토큰이 들어 있으니 공유하지 말라"고 명시합니다 — 이 파일을 열어 채팅·메일에 붙여넣지 마세요.

API 키 방식은 이 과정에서 쓰지 않습니다. codex login --with-api-key로도 되지만 요금이 사용량대로 청구되고 키 관리 부담이 생깁니다. 교육에서는 ChatGPT 계정 로그인만 씁니다.

7. 문제 해결

① 설치 스크립트가 실행되지 않음

증상

복사해서 쓰기
이 시스템에서 스크립트를 실행할 수 없으므로 C:\...\install.ps1 파일을 로드할 수 없습니다.
자세한 내용은 about_Execution_Policies를 참조하십시오.

원인 — 회사 그룹 정책이 PowerShell 스크립트 실행을 막고 있습니다. 이때는 -ExecutionPolicy ByPass도 무시됩니다.

해결 — 정책을 임의로 바꾸지 말고 9절 A의 winget 방법으로 설치합니다. winget도 막히면 전산 담당자에게 "OpenAI.Codex 설치 허용"을 요청하거나 교육 진행자에게 알립니다.

② 설치했는데 codex를 못 찾음

증상

PowerShell에 붙여넣기
codex : 'codex' 용어가 cmdlet, 함수, 스크립트 파일 또는 실행할 수 있는 프로그램 이름으로 인식되지 않습니다.

또는

복사해서 쓰기
'codex'은(는) 내부 또는 외부 명령, 실행할 수 있는 프로그램 또는 배치 파일이 아닙니다.

원인 — 설치로 추가된 PATH는 새로 연 창부터 적용됩니다.

해결 — 창을 X로 완전히 닫고 새로 연 뒤 codex --version을 다시 실행합니다. 그래도 안 되면 아래로 설치 위치를 확인합니다.

PowerShell에 붙여넣기
Test-Path "$env:LOCALAPPDATA\Programs\OpenAI\Codex\bin\codex.exe"

True면 설치는 됐고 PATH만 문제이므로 컴퓨터를 재시작하면 대부분 해결됩니다. False면 3절을 다시 하세요.

③ 로그인 브라우저가 안 열리거나 "연결할 수 없음"이 뜸

증상 — codex login 실행 후 브라우저가 안 열리거나, 열린 브라우저에 localhost에 연결할 수 없습니다가 표시됨.

원인 — 로그인은 브라우저와 내 컴퓨터가 잠깐 통신하는 방식이라, 회사 보안 프로그램·방화벽이 이를 차단하면 실패합니다.

해결 — ① PowerShell 창에 표시된 주소를 복사해 브라우저 주소창에 직접 붙여넣습니다. ② 그래도 안 되면 보안 프로그램을 끄지 말고 전산 담당자에게 "로컬 루프백(localhost) 통신 허용"을 문의합니다. ③ 교육 중이면 진행자에게 알립니다.

④ 다운로드가 중간에 멈추거나 시간 초과

증상

복사해서 쓰기
Invoke-WebRequest : 작업 시간이 초과되었습니다.

또는 ETIMEDOUT, fetch failed

원인 — 사내망·공용 와이파이 속도 문제이거나 프록시를 거쳐야 하는 환경입니다.

해결 — 같은 명령을 다시 실행합니다(중간에 멈춰도 재실행은 안전합니다). 3번 반복해도 실패하면 휴대폰 핫스팟 등 다른 네트워크로 시도하고, 그래도 안 되면 전산 담당자에게 사내 프록시 설정을 문의합니다.

⑤ 샌드박스(격리 실행) 설정에서 막힘

증상 — 실행 중 샌드박스 관련 경고가 뜨거나, 설정에 관리자 권한이 필요하다는 안내가 나옴.

원인 — Codex CLI는 AI가 함부로 파일을 건드리지 못하게 격리 공간을 만드는데, 권장 방식(elevated)은 관리자 승인이 필요합니다. 공식 문서도 회사가 관리하는 PC에서는 이 설정이 막힐 수 있다고 안내합니다.

해결 — 관리자 권한을 억지로 얻으려 하지 마세요. 실습은 승인을 하나씩 확인하는 기본 모드로 충분합니다. 경고가 떠도 1절의 원칙(읽고 승인, 실습 폴더 밖은 거절)을 지키면 그대로 진행할 수 있습니다. 실행 자체가 안 되면 진행자에게 알립니다.

⑥ 한글이 깨져 보임

증상 — 결과에 한글이 ��� 같은 기호로 나옴.

원인 — 예전 방식의 콘솔 창은 한글 표시가 불안정합니다.

해결 — Microsoft Store에서 Windows 터미널(Windows Terminal) 을 설치하고 그 안에서 PowerShell 탭을 열어 같은 명령을 실행합니다. Windows 11은 기본으로 Windows 터미널을 씁니다.

8. 제거·연동 해제

① 로그인 해제 — 교육이 끝났거나 계정을 바꿀 때 반드시 실행합니다.

PowerShell에 붙여넣기
codex logout
👀

예상 결과 — 로그아웃 완료 메시지가 나오고, 저장된 로그인 정보가 모든 위치에서 지워집니다.

auth.json을 직접 지우지 마세요. 공식 문서도 "파일을 직접 삭제하지 말고 codex logout을 쓰라"고 안내합니다. 자격 증명 저장소에 남은 정보까지 함께 지워야 하기 때문입니다.

② 프로그램 제거 — 3절(공식 설치 스크립트)로 설치했다면 아래를 실행합니다.

PowerShell에 붙여넣기
Remove-Item -Recurse -Force "$env:LOCALAPPDATA\Programs\OpenAI\Codex"

winget으로 설치했다면 이것만:

PowerShell에 붙여넣기
winget uninstall --id OpenAI.Codex

npm으로 설치했다면 이것만:

PowerShell에 붙여넣기
npm uninstall -g @openai/codex

③ 설정·기록 지우기 (선택) — codex logout을 먼저 한 뒤 실행합니다.

PowerShell에 붙여넣기
Remove-Item -Recurse -Force "$env:USERPROFILE\.codex"
👀

예상 결과 — 아무 메시지 없이 입력 대기 줄로 돌아오고, 설정(config.toml)·로그인 정보·대화 기록이 모두 사라집니다.

④ ChatGPT 계정 쪽 확인 — 브라우저에서 ChatGPT에 로그인해 설정 → 연결된 앱/기기에서 Codex 연결을 해제합니다. (메뉴 이름은 요금제·시점에 따라 다를 수 있습니다.)

9. 다른 설치 방법 (본문 방법이 막힐 때만)

A. winget 으로 설치 (스크립트가 막힐 때)

winget은 Windows에 기본 포함된 프로그램 설치 도구입니다.

PowerShell에 붙여넣기
winget install --id OpenAI.Codex
👀

예상 결과 — 사용 계약 동의를 물으면 Y 입력 후 Enter. 다운로드 막대가 지나가고 설치 완료됨 또는 Successfully installed가 표시됩니다. 이후 본문 3-3(창 닫았다 다시 열기)으로 돌아갑니다.

⚠️

이렇게 나오면 오류 — 'winget'은(는) 내부 또는 외부 명령... → winget이 없는 오래된 Windows입니다. 아래 B로 갑니다.

B. npm 으로 설치 (Node.js가 이미 있을 때)

이 과정에서 Node.js를 이미 깔았다면 이 방법도 됩니다.

PowerShell에 붙여넣기
npm install -g @openai/codex
👀

예상 결과 — 여러 줄이 지나간 뒤 added N packages in Ns 같은 줄로 끝납니다. 이후 본문 3-3(창 닫았다 다시 열기)으로 돌아갑니다.

⚠️

이렇게 나오면 오류 — 'npm'은(는) 내부 또는 외부 명령... → Node.js가 없거나 설치 후 터미널을 다시 열지 않았습니다. 공통 준비 가이드를 먼저 끝내세요.

npm 패키지 @openai/codex는 작성일 기준 최신 버전 0.146.0, Node.js 16 이상이 필요합니다.

C. WSL2 (이 과정에서는 쓰지 않음)

리눅스 도구를 함께 써야 하거나 위 방법이 모두 회사 PC에서 막힐 때의 선택지입니다. 교육 중에 필요해지면 진행자에게 문의하세요.
